# 모드 B — PRD + IA 차트 기반

## 필수 입력

(1) PRD: 제품/기능 명세·화면 설명·액션·표시정보. (2) IA 차트: 사이트맵·이동경로·Depth. 둘 다 없으면 진행불가 → 재요청.

## 흐름

1 안내 → 2 자료수집 → 3 화면리스트 도출·사용자확인 → 4 get_metadata → 5 use_figma 섹션분할 생성 → 6 get_screenshot 공유. 화면리스트는 Depth별 목록 확인 후 진행.

## 패턴

레이아웃 1440/패딩100/섹션간 80~100. Header(로고+네비+CTA h64~80). Hero(좌타이틀+우이미지 또는 중앙정렬 h480~600). 피처카드 3~4열. Stats(2~4). CTA(중앙). Footer(다크/라이트). 추가: Step·도트페이지·태그·테이블·폼·모달. 컬러/폰트/오토레이아웃=grayscale_rules. JS=figma_helpers. 패턴외(어드민·차트·지도)→회색박스+라벨.

## 에러·한계

PRD만/IA만 → 나머지 재요청. Figma MCP 부재 보고중단. 10개↑ → 3~5개 먼저. 모호하면 결과도 모호. 컬러·애니 불가. 모드 A 가 더 정확.
