# mc-logi-screen-implement — 화면 키트 기반 프론트엔드 구현 오케스트레이터

`mc-logi-screen-kit` 이 만든 로컬 화면 키트를 **단일 진실원**으로, 프론트엔드 화면 구현을 공유자산 셋업 → 스펙 → 플랜 → 화면별 구현 → 반영·추적까지 **phase 게이트로 완주**한다.

## 왜 필요한가

화면 구현은 "컴포넌트를 조립하는 일"로 보이지만, 실제로는 매 화면마다 **설계 계약을 다시 찾아 읽는 일**이다. 어떤 API 를 쓰는지, 어떤 권한이 필요한지, 수용 기준이 무엇인지, 디자인 토큰이 무엇인지 — 이걸 그때그때 찾으면 화면마다 답이 달라진다.

이 스킬은 키트가 이미 정리해 둔 그 계약을 **각 phase 에 주입**한다. 도메인 규칙·디자인 토큰·컴포넌트 카탈로그·빌드 순서를 스킬에 하드코딩하지 않고 전부 키트에서 읽으므로, 프로젝트가 달라져도 같은 절차가 성립한다.

## 게이트 4개 · 그 사이는 자율

```
Phase 0    키트 게이트      키트 존재·신선도 확인. 없으면 screen-kit 선행, stale 이면 SYNC.
                            CHANGED 가 보고되면 변경분 검토 없이 구현하지 않는다
Phase 0.5  카탈로그 시드    ui_component 가 비었으면 3출처로 시드
                            A) 레포 컴포넌트 코드 추출  B) 라이브러리 표준 지식  C) 디자인 프리셋
                            → 🚦 시드 dry 제시 + 승인
Phase 1    공유 자산 셋업   도메인 apiClient·queryKeys·types(snake_case)·zod schema + 라우팅/셸 결선
Phase 2    스펙             화면별 키트 주입(screen_spec/wireframe/AC/카탈로그 룩업) → 🚦 승인
Phase 3    플랜             태스크 = 공유자산 Task 0 → 화면별 점진 → 🚦 승인
Phase 4    화면별 구현      feature 브랜치. 화면 하나씩:
                            sections → 카탈로그 룩업 → 컴포넌트 조립 → react-query(consumes_apis)
                            → react-hook-form + zod → AC(Given/When/Then) 충족
Phase 5    반영·추적        lint+build 그린 → 🚦 머지 방식 → 머지 → 추적 역동기화
```

## 두 가지 특징

**디자인 룰이 예방과 검출 양쪽에 걸린다** — 색·간격은 디자인 시스템 토큰명만 쓴다. 임의 hex·px 하드코딩은 금지이며, **예방은 구현자 프롬프트 주입**으로, **검출은 생성 파일 raw hex grep** 으로 한다. 특정 디자인 시스템을 특별취급하지 않는다 — KRDS 도 디자인 시스템 하나일 뿐이다.

**추적 역동기화가 의무다** — 구현이 끝나면 화면별 구현기록(IMPREC)을 남기고, `register_module` + `link_ui_component_to_module` 로 **부품 ↔ 실제 `.tsx` 역링크**를 완성한다. 이게 있어야 다음 세션이 "이미 만든 컴포넌트"를 알아보고 중복 구현하지 않는다.

> 이 스킬은 설계에 **구현 기록만 쓴다.** 설계 ITEM 자체의 수정은 `mc-logi-update` 소관이다.

## 함께 쓰는 스킬

`mc-logi-screen-kit`(선행 — 키트 생성) · `mc-logi-screen-design`(디자인. 있으면 와이어프레임보다 우선 소비) · `mc-logi-update`(구현 중 발견한 설계 불일치 반영) · `mc-logi-implement`(백엔드·도메인 기능 구현)

재개 지원: "공유자산부터" · "구현만" · "추적만" · "Phase N 부터" 로 이어갈 수 있다. 선행 산출물이 없으면 어느 phase 부터 시작할지 보고 후 확인하며, **Phase 0 키트 게이트는 재개 시에도 생략하지 않는다.**
