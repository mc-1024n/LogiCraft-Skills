# mc-logi-schema-fill — 새 스키마 칸 채우기

LogiCraft 스키마 개편(«산문을 칸으로», CO-138~171)으로 **새로 생긴 칸을 기존 ITEM 마다 채우는 표준 절차**.
칸만 생겼고 기존 항목은 비어 있다 — 이 스킬이 산문(description·notes)에 이미 적혀 있던 관계와 값을 찾아 칸으로 옮기고,
근거가 없는 칸은 담당자에게 묻는 안내표로 넘긴다.

## 왜 필요한가
- **연결 칸이 비면 영향 분석이 못 본다** — cascade 는 링크만 따라간다. 산문에만 `ADR-024` 라고 적힌 항목은 그 ADR 이 바뀌어도 영향 범위에 안 뜬다(실측: 같은 ADR 의 의존자 14 → 이관 후 34).
- **구조 칸이 비면 사람이 매번 전문을 읽는다** — 이행 단계·검증 방법·사고 시각·구현 근거가 산문에 섞여 있으면 도구가 못 읽는다.
- **구조 칸에는 저장 경고가 없다** — 아무도 알려주지 않는다. 이 스킬의 진단표가 유일한 안내다.

## 무엇을 하나 (단계)
| 단계 | 하는 일 |
|---|---|
| 0 진단 | 타입·칸별 채움 현황표 · 쓰기 권한 확인(적용 단계에서 처음 알면 검토가 통째로 버려진다) |
| 1 연결 칸 | 산문 속 ID → 포인터 칸. 10부류 판정(예시·비유·경계 선언·폐기 항목·형제 프로젝트 번호는 관계가 아니다) |
| 1.5 역방향·규칙 밖 | 상대 쪽 목록이 가리키는 관계, 경고 규칙이 없는 칸(ADR→ADR 등) |
| 2 구조 칸·담당자 | 이행 단계·사고 시각·구현 근거(`evidence`)·담당자 `{kind,name}`(여럿이면 배열) |
| 3 슬림화 | 칸에 그대로 옮겨진 사실 나열만 삭제(고쳐 쓰기 금지 · 「왜」·주의는 남김) |
| 3.5 경위 분리 | 본문의 결정·정정·검증 기록을 분리 — 원문은 버전 이력에 남고 항목 상세의 변경 요약 타임라인에서 찾아간다 |
| 3.6 증적 | 검증 기록을 `evidence`(갈래·위치·날짜·결과)로 |
| 4 담당자 안내 | 못 채운 칸을 **질문 수를 줄여** 묶은 안내표(CudoCall: 102칸 → 질문 12개) |
| 5 진행 보고 | 재진단 후 전후 비교 |

## 안전장치 — AI 가 지어낸 값은 기계적으로 거부된다
- **근거 인용 대조** — 값의 근거 문장이 그 항목 산문에 글자 그대로 없으면 스크립트가 **전체를 거부**한다(하나라도 틀리면 아무것도 안 씀).
- **빈 칸만 채운다** — 이미 값이 있는 칸은 덮지 않는다.
- **경계·선례 가드** — 「범위 밖」「손대지 않」「선례」 문장이나 「잔여·후속」 절 안의 ID 는 관계로 판정하려면 사유가 필수(3개 모델 교차 판정에서 오판 4/4 를 이 신호가 잡았다).
- **증적 위치 검사** — `evidence.reference` 는 spec 이름·파일 경로·커밋 해시·CO 번호만. 설명문은 거부.
- **칸 모양 확인** — 단일 값 칸을 배열로 보내는 사고를 막으려 진단 파일(`--schemas`) 없이는 계획을 만들지 않는다.
- **사람 게이트** — 분류 확정·값 확정·적용 전 예행(dry-run)·시범 5건 → 확인 → 나머지. 쓰기는 전부 사람 승인 뒤.
- **첫 실패에서 멈춘다** — SQL·수작업으로 되돌리지 않는다. 되돌릴 땐 적용 전 스냅샷을 원본으로.

## 실측 (dev 복사본)
- **KLID 2차** — 이관 범위 370항목: 본문 387,857 → 329,224자(−15.1%), 경위 105항목 분리.
- **CatchAll** — 456항목: 링크 +238 · 구조 칸 22 · 증적 28건 · 경위 122항목 31,667자 분리. 담당자 칸 35칸은 질문 10개로 묶어 안내.

## ⚠️ 요구 서버
LogiCraft 서버 **main `36be2667` 이후**(새 칸 + `scan_prose_refs` + 이관 쓰기 전파 억제 CO-177·178·181~184).
이전 서버에 쓰면 채울 때마다 하위 항목에 「재검토 필요」가 대량으로 번진다(억제 전 실측: 더미 항목의 24~26%).

## 필요 도구
Python 3 · LogiCraft MCP(쓰기 권한 키) · 설정의 `logicraft`(상용)·`logicraft-dev` 중 대상 서버를 **말로** 확정하고 도중에 바꾸지 않는다.
