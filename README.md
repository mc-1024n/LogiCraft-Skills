# LogiCraft Skills

LogiCraft 작업용 Claude Code skill 배포 마켓플레이스.

## 설치

```
/plugin marketplace add mc-1024n/LogiCraft-Skills
/plugin install <skill>@logicraft
```

업데이트: `/plugin marketplace update logicraft`

## 수록 skill

- **mc-logi-domain-review**
- **mc-logi-integration-bootstrap**
- **mc-logi-update**
- **mc_wireframe_logicraft**

> 자동 발행 — 각 skill 은 작성자 책임. 설치 전 SKILL.md 확인 권장 (미검증).
